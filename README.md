# Kapi BM

Kapi BM is a mobile-friendly Bahasa Melayu vocabulary game for Malaysian Year 4 SJK pupils. It contains three progressively harder levels and 30 textbook-based questions.

## Levels

- Level 1: English word meanings
- Level 2: Bahasa Melayu sentence completion
- Level 3: Advanced context, inference and translation

The website is contained in `dist/`. The included GitHub Actions workflow publishes that folder to GitHub Pages whenever the `main` branch is updated.
